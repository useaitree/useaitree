    useaitree · Sustainability
    
      
    Efficient by design
    
      
    useaitree is structured to be efficient by design. These are architectural facts, not live measurements — maintainers track live figures internally.
    
      
    
        
    01
    Single-fetch navigation — pages link directly to each other, so an agent following the intended path reaches an answer in one or two fetches, by design.
    
        
    02
    Plain markdown responses — smaller than a typical rendered web page carrying scripts, styles, trackers, and ads.
    
        
    03
    Edge caching — repeat requests are served from Cloudflare's edge rather than regenerated each time.
    
        
    04
    No required client-side execution — agents read raw markdown directly, no JavaScript needs to run to get the content.
    
        
    05
    No forced re-crawling — content is linked explicitly, not rebuilt from a search index.
    
      
    
      
    We don't publish a CO₂-equivalent estimate on this public page — that number depends on assumptions that vary by methodology, and we only state it internally where it can be shown with its exact calculation.
